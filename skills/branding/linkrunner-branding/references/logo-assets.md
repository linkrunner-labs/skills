# Logo Assets

Audited against the live press page and live file bytes on 2026-08-23.

## Selection

1. Use the full lockup by default.
2. Use the mark for square or very tight slots.
3. Use the wordmark only when the mark is already nearby or the slot is short and horizontal.
4. Prefer SVG. Use PNG only when the destination cannot render SVG.
5. Use color on a light quiet canvas, ink for monochrome light layouts, and white on dark or brand-blue fields.

## Geometry

The mark is built on a 3:2:1 grid.

- Left column heights: 3x, 2x, 1x
- Right column heights: 1x, 2x, 3x
- Right upper two blocks: 20% opacity
- Column width: 25/8 x
- Every gap: 1/4 x
- Corner radius: 0

Do not redraw the mark. Scale the supplied SVG.

## Clear Space

Keep at least 1x of empty space around every edge of the mark. No text, card edge, image, or other logo may enter this zone.

## Minimum Digital Size

| Variant | Minimum width |
|---|---:|
| Full lockup | 120px |
| Mark | 24px |
| Wordmark | 80px |

## Misuse

Never:

- Recolor or apply a gradient
- Rotate or skew
- Stretch non-uniformly
- Place directly on busy photography
- Add a shadow, outline, or stroke
- Crop or rearrange the rectangles
- Recreate the ink asset using pure black
- Use legacy blue `#403DE8` in new work

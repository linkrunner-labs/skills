# Linkrunner brand instructions

For every Linkrunner-facing or Linkrunner-internal interface, document, report, deck, social asset, or partner material:

1. Load the installed `linkrunner-branding` skill before designing or reviewing.
2. Read its required brand and logo references.
3. Follow repository-local design tokens and canonical components first.
4. Use only canonical logo assets from the skill or the official URLs it lists.
5. Use Linkrunner blue `#4D4BF7`, never legacy `#403DE8`.
6. Apply the matching surface playbook rather than forcing one layout density everywhere.
7. Run the skill's brand review checklist before delivery.
8. Do not use em dashes in Linkrunner copy.
